# Free FPS Template rifle

Source package: [Free FPS Template & Tutorial](https://www.fab.com/listings/6a0af880-2b74-480c-a82c-8e597918dffe)

The imported rifle is based on "Low-Poly AAC Honey Badger" by TastyTony:
https://skfb.ly/6SMsu

The model is licensed under Creative Commons Attribution 4.0:
https://creativecommons.org/licenses/by/4.0/

This directory contains the rifle mesh and its fire/reload clips, plus the
first-person Manny arms mesh and the assault-rifle idle, fire, and reload clips
selected from the downloaded Blender source package. The original ZIP remains
outside the game bundle in the project root.
